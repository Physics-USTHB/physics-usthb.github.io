PRIVACY & LOCAL DATA

Your work should belong to you.

Default model: this website has no student accounts, no application database, and no analytics code. Lab progress and LaTeX projects are stored in the browser that you are using. Separate devices or browser profiles have separate data.

Physics practicums

TP1–TP5 save experimental progress and report text to this browser's localStorage so a page can be reopened without starting again. Student name and group are deliberately not persisted; they remain only in the open page. Each practical has a Clear local data button in the Report tab.

LaTeX Studio

LaTeX Studio stores projects locally, preferring IndexedDB and falling back to localStorage when necessary. It can request browser “persistent storage” to reduce the chance of automatic eviction. ZIP export remains the safest portable backup. Clearing browser site data can delete locally stored projects.

PDF compilation runs in the browser through a WebAssembly pdfLaTeX engine. The project source is not intentionally sent to a compilation server. The browser still downloads application, font, TeX-engine and package assets from the website and configured dependency hosts, so those network providers can receive ordinary connection metadata such as IP address and user agent.

Shared computers

Browser storage is isolated by website and browser profile, not by the person's identity. Two people using the same browser profile can potentially see the same saved local projects or lab progress. On a shared computer, use a separate browser/OS profile or private window where appropriate, export anything you need, then use the available clear-data controls.

Many users at the same time

The published site is static and each visitor runs an independent copy in their own browser. Many students can therefore use the practicums and LaTeX Studio simultaneously without sharing each other's work. Real-time co-editing of one LaTeX project or a shared lab session is not enabled in the current release; that requires an explicit collaboration layer with its own privacy design.

Hosting and third parties

  • The public site is hosted by GitHub Pages. GitHub may process visitor connection data under its own policies, including IP addresses for security.
  • Some browser libraries are loaded from jsDelivr; the local TeX runtime downloads pinned static engine/package assets from GitHub raw-file infrastructure.
  • Following an external link takes you to that provider and its privacy policy.

See GitHub's privacy statement and jsDelivr's privacy information for their practices.

What this site does not currently do

It does not require login, build a central student profile, upload lab reports to the project owner, or provide teacher access to private student work. If account sync, submissions, or real-time collaboration are introduced later, they should be opt-in and accompanied by a separate data-access and retention design before deployment.
