Diffraction Gratings

Curriculum-aligned spectrometer work using symmetric spectral-order readings to calibrate an unknown grating and then determine an unknown wavelength.

Grating equation

For normal incidence, spectral maxima satisfy:

d sinθ = mλ

Use known spectral lines first to determine the unknown grating spacing/density. Only then use the calibrated grating to determine the unknown source wavelength.

Symmetric angular measurement

Measure the same spectral order on the left and right of the zero-order beam. Use half the angular separation to reduce zero-reference error:

θ = |θR−θL|/2

Repeat across several physically available orders.

Theoretical background

A diffraction grating contains many equally spaced slits. Constructive interference occurs when the path difference between adjacent slits is an integer number of wavelengths: d sinθ=mλ. More slits make the principal maxima narrow, allowing nearby wavelengths to be distinguished more precisely than with a double slit.

The angular separation of spectral lines grows with diffraction order and depends on the grating spacing d. Measuring symmetric ±m orders reduces zero-angle error. Once d has been calibrated with known wavelengths, the same equation can be inverted to determine an unknown wavelength from its measured diffraction angle.
