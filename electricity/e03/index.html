Current–Voltage Characteristics of Electrical Dipoles

Undergraduate75–100 minDC circuits Measurement uncertaintyRegression
Experiment mode
Guidance and diagnostic hints are available.

Learning outcomes

By the end of this experiment you should be able to:

  1. measure the current–voltage characteristic of an ohmic resistor and a tungsten-filament lamp;
  2. correct the current for voltmeter loading in the measurement topology used here;
  3. propagate instrumental uncertainty into the corrected dipole current;
  4. estimate resistance using uncertainty-aware linear regression and judge model adequacy using residuals and reduced χ²;
  5. distinguish static resistance V/I from differential resistance dV/dI for a nonlinear device;
  6. construct series and parallel characteristics from measured component characteristics.

Measurement model

For an ideal ohmic dipole,

V = RI.

In the short-derivation connection used here, the ammeter reads the current through the dipole plus the current drawn by the voltmeter:

Im = ID + IV,    IV = V/RV.

Hence

ID = Im − V/RV.

If the standard uncertainties of Im and V are independent, the corrected-current uncertainty is approximated by

u(ID) = √[u(Im)² + (u(V)/RV)² + (V·u(RV)/RV²)²].

The filament lamp

The lamp is modelled as a tungsten-like filament in steady thermal equilibrium. Its resistance increases with temperature, while electrical power is balanced by convective/conductive and radiative heat losses:

R(T) ≈ R0[1 + α(T − T0)]
I²R(T) = H(T − T0) + K(T⁴ − T0⁴).

This produces a nonlinear steady-state characteristic. The model is pedagogical: it captures the dominant electro-thermal feedback without claiming to reproduce a specific commercial lamp.

Protocol

  1. Start near 0 V. Measure the resistor at 6–10 well-spaced source settings.
  2. Repeat for the filament lamp. Avoid clustering all points at high voltage.
  3. Inspect uncertainties and the loading correction in the Data tab.
  4. Fit the resistor with the uncertainty-aware model. Inspect the residual plot and reduced χ².
  5. Characterise the lamp using static and local differential resistance.
  6. Use both measured datasets to synthesize series and parallel characteristics.
  7. Complete the assessment and write the report in scientific prose.

Residuals — resistor model

Residual = measured V − fitted V. A useful model should not leave a systematic pattern.

Interpretation guide

R²Describes how much variation is explained by a linear relation, but does not by itself validate the model.
Reduced χ²Compares residual size with stated measurement uncertainty. Values of order unity are expected when model and uncertainties are mutually consistent.
Residual structureCurvature or trends can reveal model inadequacy even when R² is very high.
Fit used hereIterative effective-variance weighted least squares with σ²eff=u(V)²+[m·u(I)]².
