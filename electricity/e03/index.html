Official objectives

This virtual laboratory preserves the three central objectives of Practical 3:

  1. build and use an adjustable voltage source based on a potentiometric resistance box;
  2. plot the characteristics of passive dipoles and combinations of dipoles;
  3. interpret the characteristics and determine resistance values.
VAB = E · RAB / (RAC + Rg)

The official resistance box has eleven 1 Ω resistors in series between A and C, so RAC = 11 Ω. The selector sets RAB from 0 to 11 Ω.

Laboratory safety and connection rules

✓
The generator is connected between A and C; the measurement circuit is connected between A and B.
✓
The wiring is checked before the source is energised.
✓
Measurement instruments are initially placed on their maximum range before changing ranges.
✓
Before changing the circuit, the source is disconnected first and the wiring is then reconfigured.
Why this matters: the virtual bench enforces a wiring-verification step whenever you change the dipole configuration.

Short-derivation connection

The voltmeter is connected directly across the dipole. The ammeter therefore measures

Im = ID + IV.

In the official practical, the graph is plotted using the measured current Im. The approximation Im ≈ ID is acceptable because the voltmeter input resistance is very large compared with the tested dipoles.

Extension

Voltmeter-loading correction

Because the ammeter reads the dipole current plus the voltmeter current, a refined estimate is

ID = Im − V/RV.

With RV = 10 MΩ, the correction is small but measurable in principle. The table below shows the correction and propagated standard uncertainty for the resistor data.
