Vibrating String

USTHB detector-based free-vibration experiment for deriving the fundamental string law experimentally.

Vibrating string detector

A fishing line is stretched between two knife-edge supports by a calibrated spring/dynamometer. A lamp and photodetector are aligned so the resting string masks the detector junction. During vibration, detector pulses mark crossings.

f₁ ∝ L^α F^β μ^γ

USTHB log–log programme

  • At F=25 N, measure ~10 lengths from 40–80 cm → α.
  • At L=50 cm, measure ~10 tensions from 10–30 N → β.
  • At L=50 cm, F=15 N, use different strings/μ → γ.
  • Infer the complete fundamental-frequency relation.

String + lamp + detector
