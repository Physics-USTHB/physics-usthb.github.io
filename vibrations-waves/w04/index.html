Vibrating-string detector

A stretched string masks a lamp/photodetector junction at equilibrium. Each time the vibrating string crosses the equilibrium line the detector produces a pulse, so there are two detector pulses per mechanical oscillation.

USTHB log–log programme

  • At F=25 N and μ=1.10 g·m⁻¹, measure about ten lengths from 40–80 cm → α.
  • At L=50 cm and μ=1.10 g·m⁻¹, measure about ten tensions from 10–30 N → β.
  • At L=50 cm and F=15 N, use all available strings → γ.
  • Infer f₁ ∝ LαFβμγ and compare with the theoretical exponents.

Theoretical background

Small transverse waves on a stretched string travel with speed v=√(F/μ), where F is the tension and μ the linear mass density. A string fixed at both ends supports standing-wave modes with fn=n v/(2L); for the fundamental, f=(1/2L)√(F/μ).

The theory predicts the power-law dependences f∝L−1F1/2μ−1/2. Taking logarithms converts these into straight-line slopes, which is why the practical extracts the exponents from log–log graphs. The optical detector produces two pulses per mechanical cycle because the string crosses its equilibrium line twice per oscillation.

String + lamp + photodetector

First align the detector so the resting string masks the junction and the pulse train is symmetric. Then time several pulse intervals with the graticule.
