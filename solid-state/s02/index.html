Elastic torsion

The USTHB programme specifies isotropic elasticity by torsion pendulum. A detailed public equipment sheet is not exposed, so this reconstruction uses standard static and dynamic torsion measurements while keeping all derived quantities in the student workflow.

τ=Cφ
T=2π√(I/C)

Wire shear modulus

For a circular wire of measured length L and radius r:

C=πGr⁴/(2L)
G=2LC/(πr⁴)

Because of the fourth power of radius, diameter/radius measurement is a dominant source of uncertainty.
