    Local compilation

    Compilation runs inside this browser with a WebAssembly pdfLaTeX engine. Your project source is not uploaded to a compile server.

    The first compilation downloads a pinned pdfTeX engine and TeX package files. The asset host can see ordinary network metadata such as your IP, but the editor does not send it your document text.

    Storage & privacy

    Checking browser storage…

    Shared computer: browser-local storage is private between different browser profiles/devices, but not between people who share the same browser profile. Export your work and clear local projects when finished on a public computer.

    Simultaneous use

    Many people can use the site at the same time because each browser has an independent workspace. Real-time co-editing of the same project is a separate collaboration feature and is not enabled yet.

    Prism migration

    1. Export your Prism projects to ZIP before January 1, 2027.
    2. Choose Import ZIP / files to restore a project here.
    3. Check the main .tex file, edit and export a backup.

    ZIP import preserves source files, bibliography files and images; it does not restore Prism comments, history or collaborators.
