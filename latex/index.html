    Prism migration

    1. Export your Prism projects to ZIP before January 1, 2027.
    2. Choose Import ZIP / files to restore a project here.
    3. Check the main .tex file, edit and export a backup.

    ZIP import preserves source files, bibliography files and images; it does not restore Prism comments, history or collaborators.
